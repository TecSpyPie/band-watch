Install Band Watch

Choose where you want Band Watch. It's free, and it works the same everywhere.

Windows PC

Band Watch is installed on this PC and running now.

The Windows app (recommended)

  1. Get BandWatch-Windows.zip, the Windows package (M3vrv can send it to you). Download for Windows
  2. Right-click the zip and choose Extract All.
  3. In the extracted folder, double-click install.bat and choose 1 (Windows). Or double-click Install Band Watch (automatic).bat to install with the usual choices.
  4. Open Band Watch from the desktop or the Start menu.

If Windows says "Windows protected your PC", click More info, then Run anyway. If Smart App Control is on, Windows blocks BandWatch.exe without asking; Band Watch then runs with Node.js instead, so install Node.js LTS if you don't have it.

Or as a web app

In Microsoft Edge or Google Chrome, open band-watch.ample.run and click the install icon at the right of the address bar (or ⋯ menu, Apps, Install Band Watch).

iPhone or iPad

  1. Point your iPhone camera at this code and tap the link. Or type band-watch.ample.run into Safari.
  2. In Safari, tap the Share button ⬆ (at the bottom on iPhone, top right on iPad).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add. Band Watch is now on your Home Screen and opens full screen like any app.

Use Safari: on iOS 16.3 and earlier only Safari can add apps to the Home Screen. Band Watch isn't in the App Store; it runs from the web, so it needs an internet connection for live spots. Listening opens the web receiver in Safari.

Android phone or tablet

  1. Point your phone camera (or Google Lens) at this code and tap the link. Or type band-watch.ample.run into Chrome.
  2. In Chrome, tap Install when Chrome offers it, or tap the ⋮ menu and then Install app (on some phones Add to Home screen).
  3. Tap Install. Band Watch appears with your other apps and opens full screen.

Samsung Internet and Firefox can add it too, from their menus. Band Watch isn't in the Play Store; it runs from the web, so it needs an internet connection for live spots.

Your settings on each device

Each device keeps its own settings. To copy yours across, open Settings, then Profiles, and choose Save to a file; on the other device use Load from a file.
